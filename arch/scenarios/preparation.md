# Подготовка и замена программ

Эти сценарии следуют из [модели управления](../control-model.md#control-loop): регулятор может включать KeyBridge только после подготовки пригодных программ и настройки поиска лицензии в локальной 1С. Подготовка, работа с ключом и подтверждённое получение лицензии — разные результаты.

Здесь описано требуемое поведение. Его связь с кодом и оставшиеся ограничения находятся в [реализации](../implementation.md).

## Установить программы из своих файлов

**Условие:** пользователь впервые открывает KeyBridge либо выбирает переустановку. Для изменения программ работа с ключом должна быть подтверждённо остановлена.

Приложение уже содержит подготовленную основу Alpine с glibc. Пользователь добавляет только два компонента: менеджер лицензий из полного установщика 1С для Linux и драйвер HASP. Можно выбрать готовый файл `.run` или `.deb`, а также ZIP или tar-архив, в том числе с вложенными архивами. KeyBridge сам находит и извлекает компонент; ручная распаковка не требуется. Проверка и установка используют отдельные копии основы; загрузка Linux и пакетов при первом запуске не требуется.

| Ситуация и наблюдение | Решение и действие | Ожидаемый исход |
| --- | --- | --- |
| Файлы ещё не выбраны | Показать назначение каждого файла, формат и ссылку «Скачать с сайта…» непосредственно возле его выбора | Пользователь понимает, что скачать и какой файл указать; инструкция не разделена между несколькими местами |
| Выбран архив | Найти компоненты, извлечь их в закрытый временный каталог, отсеять другие типы и архитектуры | Исходный архив сохранён; посторонние файлы не устанавливаются |
| В архиве найдено несколько подходящих компонентов | Показать найденные файлы и предложить выбрать один | Приложение не выбирает произвольно первую или самую новую версию |
| Выбран установщик 1С | Сразу проверить Linux ELF x86-64, затем выполнить `--version` и `--help` в отдельной проверочной Alpine; потребовать узнаваемый установщик 1С и заявленный компонент `lic_manager` | Отсутствие менеджера обнаружено до установки; до окончания проверки продолжение недоступно |
| Выбран драйвер HASP | Сразу проверить DEB, метаданные `aksusbd` и `amd64`, полноту архива данных и нужные исполняемые программы x86-64 внутри него | Одних метаданных или имени файла недостаточно; другая версия сама по себе не запрещает установку |
| Выбран неподходящий файл | Показать причину возле этого файла и действие замены; продолжение заблокировать | Другой пригодный файл остаётся выбранным; после замены прежняя ошибка исчезает |
| Проверка файла прервана, истёк срок ожидания или пользователь выбрал другой файл | Прекратить прежнюю проверку, показать применимый результат возле текущего выбора | Поздний ответ не признаёт новый файл пригодным; второй выбранный компонент сохранён |
| Проверка обоих файлов пройдена, места хватает | По явному действию пользователя создать отдельную копию основы, передать проверенные копии компонентов, повторно проверить состав, установить компоненты, проверить результат и остановить её | Текущая рабочая установка не изменяется во время подготовки |
| Подготовка закончена и проверена | Одним переключением сделать новую установку текущей | Программы установлены; следующий шаг — настройка поиска лицензии или явное включение |

Возле установщика нужна ссылка на [портал релизов 1С](https://releases.1c.ru/project/Platform85), возле драйвера — на [драйверы Sentinel на сайте Thales](https://supportportal.thalesgroup.com/csm?_runtime_packages=&id=kb_search&query=kbcat_drivers_%26_runtime_packages&u_products_available_in_portal_search=50303b92db852e00d298728dae96199d). Это страницы поставщиков, а не обещание скачать определённую версию без входа. Для драйвера поясняется выбор Linux, Debian/Ubuntu, amd64 и DEB; архив поставщика можно выбрать целиком. Справка остаётся доступной после выбора файла, не исчезает ниже внезапной прокрутки.

Результат проверки связан с отдельной копией выбранного компонента. Именно эта копия передаётся на установку: изменение или удаление исходного архива после выбора не подменяет проверенные данные. Версия и заранее известный хеш не служат списком разрешённых установщиков. Проверка неизменности файла во время переноса решает другую задачу: устанавливаются именно проверенные данные.

Проверка установщика выполняется без подключения USB-ключа и без установки компонентов. Заявленный в `--help` менеджер ещё не доказывает, что установка завершится успешно. После установки KeyBridge по-прежнему проверяет наличие единственного пригодного менеджера и готовность служб. Ни ранняя проверка, ни готовность служб не подтверждают выдачу лицензии в 1С.

### Если подготовка не завершилась

| Ситуация и наблюдение | Решение и действие | Ожидаемый исход |
| --- | --- | --- |
| KeyBridge ещё работает или его остановка не подтверждена | Предложить [выключение](operation.md#выключить-keybridge-или-завершить-приложение), не начинать новую подготовку | Нет второй работающей копии и передачи ключа неизвестному владельцу |
| На Mac или внутри подготавливаемого Linux не хватает места | Остановить подготовку, назвать установленное место отказа, предложить освободить место и проверить снова | Рабочая установка сохранена; она не удаляется ради продолжения |
| В установщике нет компонента менеджера лицензий либо после установки нет пригодного исполняемого менеджера | Объяснить отсутствие нужного компонента, признать выбранный установщик неподходящим; основное действие — выбрать другие файлы | Повтор с прежним установщиком не предлагается; выбранный драйвер сохраняется, рабочая установка не меняется |
| Установщик оставил несколько менеджеров и невозможно однозначно выбрать один | Объяснить неоднозначный состав и предложить другой установщик | Приложение не выбирает менеджер произвольно и не включает неподтверждённую установку |
| Установщик завершился ошибкой либо не ответил за отведённое время | Завершить подготовку с объяснением; предложить повтор или другие файлы | Нет бесконечного ожидания; сообщения о живом процессе не выдаются за продвижение установки |
| Файл изменился или перенос повреждён | Прервать подготовку и предложить заново выбрать соответствующий файл | Повреждённая копия не становится текущей |
| Пользователь отменил установку | Прекратить незавершённые действия и остановить подготавливаемую копию | Поздний ответ не завершает отменённую установку; выбранные пригодные файлы доступны для повтора |
| Приложение или агент перезапустились около завершения | Сопоставить сохранённый результат переключения с попыткой подготовки | До переключения текущей остаётся прежняя установка; после него показывается новая. Одновременных «отменено» и скрытого переключения нет |
| Повреждены основа, диск или сведения о текущей установке | Назвать непригодный объект, предложить повторную установку или доступный возврат | Наличие файла само по себе не означает готовность; неизвестная установка не запускается |

Успешная подготовка не включает KeyBridge автоматически и не снимает сохранённый запрет возобновления после выключения. Опубликованные установки сохраняются; остатки подготовки учитываются в [сведениях о ресурсах](settings.md#посмотреть-память-и-занятое-место).

## Настроить поиск лицензии в локальной 1С

Сценарий следует из границы объекта управления: исправные программы выдачи сами по себе не направляют локальную 1С к KeyBridge.

**Условие:** программы установлены, KeyBridge выключен. Приложение проверяет наличие подходящего клиента 1С для macOS и состояние его настроек.

| Ситуация и наблюдение | Решение и действие | Ожидаемый исход |
| --- | --- | --- |
| Подходящая 1С найдена, поиск ещё не настроен | Объяснить изменение адреса поиска лицензии; по действию «Настроить поиск лицензии» сохранить исходные настройки и запросить необходимые права macOS | Настройка завершена только после подтверждённой записи. Базы и конфигурации 1С не изменены |
| Клиент отсутствует или не подходит | Показать инструкцию и ссылку на портал 1С; после установки предложить «Проверить наличие 1С» | Linux-файл `.run` не предлагается вместо клиента macOS; после обнаружения клиента доступна настройка |
| Поиск уже настроен KeyBridge | Перейти к допустимому включению без повторной записи | Замена программ не требует заново менять исправные настройки клиента |
| Настройки внешние или изменились после подключения | Открыть [сценарий исправления настроек](diagnostics.md#исправить-настройки-поиска-лицензии) | Автоматической перезаписи нет; пользователь получает объяснение и конкретное продолжение |
| macOS отклонила запрос или пользователь отменил его | Оставить прежние настройки, показать отказ возле действия; дать повторить запрос или отменить настройку | Отказ администратора не обходится; лицензия не объявляется доступной |
| Запись завершилась ошибкой, истёк срок ожидания или результат неизвестен | Показать установленный отказ либо неизвестность и предложить повторную проверку состояния | Неизвестный исход не называется успешной настройкой |

Успешный исход — локальная 1С ищет лицензию через KeyBridge. Это ещё не свидетельство выдачи лицензии.

## Переустановить компоненты

Сценарий следует из [правил сохранности](../control-model.md#safety): обновление должно оставлять возможность продолжить работу с прежней пригодной установкой.

**Условие:** есть текущая установка; пользователь открывает переустановку в настройках.

1. Приложение объясняет необходимость выключения и сохранение прежней установки.
2. После подтверждённого выключения пользователь выбирает файлы и проходит подготовку, описанную выше.
3. При успешном завершении новая установка становится текущей. Пользователь явно включает KeyBridge; проверка лицензии доступна отдельно в диагностике.

Отмена или отказ до переключения оставляют текущей прежнюю установку. Если программы установились, но запуск или проверка не удались, приложение предлагает доступные повтор, диагностику и возврат. Успешная установка не выдаётся за успешную выдачу лицензии.

Сведения о программах всегда относятся к действительно выбранной установке. Переустановка после возврата не сохраняет на новых компонентах старую подпись «Предыдущая версия».

## Вернуть предыдущую версию после проблемы с обновлением

Этот сценарий — способ восстановить пригодный объект управления, когда новая установка не работает. Он предлагается в контексте проблемы; пользовательского каталога сохранённых установок нет.

**Условие:** после обновления возникла проблема, прежняя установка сохранена, KeyBridge подтверждённо выключен.

| Ситуация и наблюдение | Решение и действие | Ожидаемый исход |
| --- | --- | --- |
| Предыдущая установка доступна и пригодна | По действию «Вернуть предыдущую версию» переключить текущую установку | Возврат подтверждён; для начала работы требуется явное включение |
| KeyBridge ещё работает | Сначала предложить выключение | Переключение не выполняется под работающей программой выдачи |
| Предыдущей пригодной установки нет | Объяснить недоступность возврата, предложить переустановку | Недоступное восстановление не обещается |
| Предыдущая установка повреждена или переключение завершилось ошибкой | Показать причину и допустимый повтор после исправления либо переустановку | Текущая установка остаётся выбранной; данные не удаляются |

Прежний успешный результат проверки лицензии после возврата остаётся историческим. Если повторная проверка новой установки достоверно подтвердила выдачу, опровергнутая проблема обновления исчезает; последующее выключение не возвращает эту ошибку.
